# Fabula
Tercer y último proyecto de la *Trilogía de una ciudad y su gente*.


## Etructura de repositorio

La carpeta *Fabula-godot* contiene el proyecto de Godot con todos los elementos pertenecientes al proyecto.

Este proyecto se puede abrir con el motor de descarga gratuita Godot (https://godotengine.org/)

Igualmente, sin el programa se puede navegar por los ficheros del proyecto y observar el trabajo realizado. Todos los ficheros (código, modelos, texturas, escenas) han sido creados manualmente sin asistencia de modelos de inteligencia artificial generativa.
